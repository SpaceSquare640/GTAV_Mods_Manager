Profiles

A profile is a set of mods that belong together. Joining one is opt-in: a mod in no profile is never touched by switching. Switching disables what the target profile does not want and enables what it does, using the same enable and disable paths as the rest of the app.

A built-in starting list of the prerequisite tools almost every Legacy single-player setup needs before mods go on. You can edit or remove any of these; new links belong on the My Links tab.

Script Hook V
http://www.dev-c.com/gtav/scripthookv/ The foundation nearly every .asi script mod depends on. Legacy only — Enhanced needs RAGE Plugin Hook instead — and the version must match your game build exactly or the game will not launch.
Packfile Limit Adjuster
https://www.gta5-mods.com/tools/packfile-limit-adjuster Raises how many RPFs the game can load at once — the fix for the common packfile limit crash once enough add-ons are installed.

LSPD First Response
https://www.lcpdfr.com/downloads/gta5mods/g17media/7792-lspd-first-response/ The core plugin that turns GTA V into a police roleplay game. Runs on RAGE Plugin Hook, and is officially supported on Legacy only. Some antivirus software flags it as a false positive because of how it hooks memory.
EUP Badges
https://www.lcpdfr.com/downloads/gta5mods/misc/32225-eup-badges/ Prop badges for the LSPDFR flash-badge feature. Packaged as an .oiv, so install it with OpenIV — this application never installs .oiv packages itself.

1. No warranty

GTAV Mods Manager is free, for non-commercial use, and provided as-is. There is no guarantee against game instability, save corruption, or action taken by an online service as a result of third-party mods you choose to install.

2. Official builds only

Support and safety guarantees apply only to builds downloaded from this project's official GitHub Releases. Modified or third-party redistributions are used entirely at your own risk. Every release publishes a SHA-256 checksum you can verify with the Hash Calculator.

3. Your responsibility

You are responsible for reviewing what a mod does before installing it. The conflict checker and the protected-file guard reduce risk; they do not eliminate it.

4. Protected files

The application refuses to write to game executables, Rockstar online components and anti-cheat binaries. This guard cannot be overridden from the interface, by a profile, or by the AI assistant.

5. Online play

Do not use single-player modifications while connected to GTA Online. This tool is for single player, LSPDFR and FiveM only, and cannot detect or prevent misuse on your behalf.

6. Trademarks

Grand Theft Auto and related marks belong to their respective owners. This project is unofficial and is not endorsed by or affiliated with Rockstar Games or Take-Two Interactive.

1. Offline by default

Everything runs on your machine. There is no account, no telemetry, and no first-party server. The application makes no network request unless you ask it to.

2. What leaves your machine, and only when you ask

Checking for updates queries the GitHub Releases API when you press the button. Enabling the AI assistant with a cloud provider sends the text you submit to the endpoint you configured, under your own API key. Crash reporting opens a pre-filled GitHub issue in your browser for you to review and submit — nothing is sent automatically.

3. De-identification

Before any text is sent to an AI provider or placed into a crash report, paths inside your home directory are stripped.

4. Credentials

An API key you provide is stored in the operating system's credential manager, never in the application database and never in a configuration file.

5. Local files

The database, backups and the diagnostic log stay in your application data folder. The diagnostic log clears itself every three days.
