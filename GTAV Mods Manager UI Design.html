Profiles

A profile is a set of mods that belong together. Joining one is opt-in: a mod in no profile is never touched by switching. Switching disables what the target profile does not want and enables what it does, using the same enable and disable paths as the rest of the app.

DLL Translation

Translates the interface text baked into a .NET mod DLL by patching the binary directly — no source code and no recompilation. Requires the AI assistant to be enabled with a provider first, unless you type every translation yourself.

Pick file
Extract strings
3Review & translate
4Patch & save

H:\...\Plugins\StoryCallouts.dll

Found 7 translatable strings out of 11 — 4 technical identifiers such as animation names and file paths were excluded automatically.

Every field is editable. Fill them with AI and adjust by hand, or type them all yourself — each starts pre-filled with the original, so leaving one untouched is safe. Markup such as ~g~ and ~r~ is preserved.

~g~Suspect detained.
~r~Callout failed.
Press ~o~E~s~ to begin the investigation.
Output file H:\...\Plugins\StoryCallouts.zh-TW.dll — default, beside the original
Only IL-only, unsigned assemblies can be patched. Signed, mixed-mode or obfuscated DLLs are refused rather than attempted, because a patch would break the signature or the structural scan cannot locate strings reliably.

Saved Links

Bookmarked mod pages, kept independently of what is installed — a link is worth saving before you download and after you uninstall. Nothing here is fetched or checked; they are only links.

NaturalVision Evolved
https://www.naturalvision.co/ Graphics overhaul — check compatibility with your gameconfig before installing.

A built-in starting list of the prerequisite tools almost every Legacy single-player setup needs before mods go on. You can edit or remove any of these; new links belong on the My Links tab.

Script Hook V
http://www.dev-c.com/gtav/scripthookv/ The foundation nearly every .asi script mod depends on. Legacy only — Enhanced needs RAGE Plugin Hook instead — and the version must match your game build exactly or the game will not launch.
Packfile Limit Adjuster
https://www.gta5-mods.com/tools/packfile-limit-adjuster Raises how many RPFs the game can load at once — the fix for the common packfile limit crash once enough add-ons are installed.

A built-in starting list of LSPDFR and EUP mods from lcpdfr.com. You can edit or remove any of these; new links belong on the My Links tab.

LSPD First Response
https://www.lcpdfr.com/downloads/gta5mods/g17media/7792-lspd-first-response/ The core plugin that turns GTA V into a police roleplay game. Runs on RAGE Plugin Hook, and is officially supported on Legacy only. Some antivirus software flags it as a false positive because of how it hooks memory.
EUP Badges
https://www.lcpdfr.com/downloads/gta5mods/misc/32225-eup-badges/ Prop badges for the LSPDFR flash-badge feature. Packaged as an .oiv, so install it with OpenIV — this application never installs .oiv packages itself.
